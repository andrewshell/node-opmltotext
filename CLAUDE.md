# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Architecture

`getText` walks the outline tree iteratively rather than recursively. `_buildResult`
drains a flat `stack` that holds two kinds of entry:

- **outline nodes**, which emit a line and push their children onto the front
- **placeholder objects** (`isPlaceholderInfo: true`), which carry no output and
  exist only to restore `nestingLevel`, `inComment`, and `preCommentNestingLevel`
  when a subtree ends

A placeholder is pushed immediately behind a node's children, so it is popped once
those children are exhausted. That is the only unwind mechanism — there is no
recursion to return from.

The XML layer is deliberately thin. `tagName` / `children` / `attr` /
`childElements` / `findFirstDescendant` wrap fast-xml-parser's `preserveOrder`
output and are the only code that knows about the `:@` attributes key or the `@_`
attribute prefix. The traversal above them was ported unchanged from the original
libxmljs implementation.

## Behavioral contracts to preserve

- **Attribute values are never trimmed or coerced.** The parser is configured with
  `trimValues: false` and `parseAttributeValue: false` so `text="  padded  "` keeps
  its whitespace and `text="007"` stays a string, matching the libxmljs behavior
  published consumers depend on.
- **`example/example.md` is a golden fixture** generated by the original 0.2.0
  implementation. The test asserting it matches byte for byte is the fidelity check
  against the pre-rewrite behavior — do not regenerate it to make a test pass.
- **Comment prefixes sit at the depth the comment started**, not at the node's own
  depth. `_getLinePrefix` indents to `preCommentNestingLevel`, inserts the prefix,
  then indents the remainder.
- `children()` must return `[]` for text nodes. fast-xml-parser gives `#text`
  entries a bare string value, and treating that as an array makes
  `findFirstDescendant` recurse into individual characters.
